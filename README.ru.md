# Mod Settings Folders

Отдельный клиентский мод для Project Zomboid Build 42: сворачиваемые папки разделов в **Настройки → Моды**. Штатные элементы настроек остаются на месте, с исходными обработчиками и назначениями клавиш.

## Установка

Запустите `ModSettingsFolders-Setup-0.1.5.exe` и выберите пользовательский каталог Zomboid. Игру перед установкой нужно закрыть. Прежняя версия сохраняется в `ModSettingsFoldersBackups`, настройки и список включённых модов не меняются. После установки включите мод и перезапустите игру. Установщик без цифровой подписи, не скачивает зависимости и не требует прав администратора. Нужен .NET Framework 4.5 или новее (обычно уже есть в Windows 10/11).

Для ручной установки распакуйте `ModSettingsFolders-0.1.5.zip` в папку `mods` пользовательского каталога Zomboid. Должен получиться путь `mods/ModSettingsFolders/42/mod.info`. Включите **Mod Settings Folders** и перезапустите игру, чтобы загрузился код главного меню.

Обычно пользовательский каталог — `%USERPROFILE%/Zomboid`; параметр `-cachedir` может его изменить. Java, серверная часть и самолётные моды не нужны. Используется встроенный API Build 42; Build 41 не поддерживается.

## Управление

- **Создать папку** — новая группа разделов.
- ПКМ по разделу → **Переместить в папку**.
- ПКМ по папке — переименование, перемещение выше/ниже, удаление.
- Нажатие на папку сворачивает её; на раздел — открывает его настройки.
- **Все разделы** показывает полную форму. Новые разделы попадают в **Без папки**.
- Удаление папки сохраняет её разделы и их настройки.
- При небольшой ширине окна есть переключатель **Папки / настройки**.
- Геймпад: стрелки выбирают строку; A открывает, X вызывает контекстное меню, Y создаёт папку. B возвращает из формы в список, затем вызывает штатный выход из настроек. Бамперы переключают вкладки.

Папки сохраняются сразу. Сами настройки применяются и отменяются штатными кнопками игры. Переключение разделов не сбрасывает ещё не применённые изменения.

## Хранение и совместимость

Схема папок хранится локально в `ModSettingsFolders.cfg`, предыдущая исправная версия — в `ModSettingsFolders.previous.cfg`. Оба файла находятся в пользовательском каталоге Zomboid. Привязка идёт по ID раздела, поэтому перевод названия не перемещает его в другую папку. Привязки отключённых модов сохраняются.

При повреждении основного файла используется резервный. Если оба непригодны или формат новее поддерживаемого, остаётся обычная форма настроек, файлы не перезаписываются. Для сброса папок закройте игру и перенесите оба файла из пользовательского каталога. Значения настроек остаются в штатном `ModOptions.ini`.

Поддерживаются разделы встроенного `PZAPI.ModOptions`. Отдельные самописные окна, настройки песочницы и список включения модов не группируются. При несовместимой перестройке меню другим модом предусмотрен возврат к штатной форме; совместимость с любыми заменами интерфейса не гарантируется.

Папки одноуровневые. Ограничения: 99 папок, 160 кодовых единиц UTF-16 в названии, 2000 сохранённых привязок. Есть русский и английский интерфейс. Схема общая для пользовательского каталога, не привязана к сохранению или серверу.

Автоматические проверки выполнены на установленной Kahlua и исходном построителе формы игры, с подменами UI и файлов. Визуальная проверка непосредственно в игре ещё требуется: это первая тестовая версия. Подробности — в `docs/verification.md`.

Поиск над «Создать папку» ищет во всех папках без учёта регистра; Ctrl+F переводит фокус в строку.
